# Live Notes 网页控制台

此目录可直接部署到 Vercel，作为静态网页托管，无需安装依赖或运行构建。

网页需要配合电脑上的最新版本地工具。音视频下载、Whisper 转录、Ollama 分析和历史记录都由本机工具处理；Vercel 不提供转录后端。

## 配对使用

1. 部署此目录，取得网页的 HTTPS 地址。
2. 在电脑上启动本地工具，并使用 `--portal https://你的网页地址` 参数。
3. 本地工具会打开带有临时配对片段的网页：`#bridge=本机地址&token=本次启动的令牌`。
4. 浏览器若请求「本地网络访问」权限，请允许；连接成功后即可提交 Facebook 录像链接、导入音视频或逐字稿。

也可以把本地工具生成的完整配对链接粘贴到网页，再点击「连接本机工具」。只支持本机 `http://127.0.0.1:1024–65535`；不会扫描本机端口。

连接令牌只保存在当前标签页的 sessionStorage 中；启动链接中的片段会立即从地址栏移除。令牌不会写入网页文件或发送给 Vercel。每次重启本地工具会生成新令牌，请使用新的配对链接。勿分享配对链接。

「断开网页连接」会保留本机正在进行的任务；「关闭本机工具」会停止程序及尚未完成的任务。关闭标签页也不会停止本机任务，重新配对后可从「本地历史」查看记录。

## 部署设置

- Root Directory：此 `web` 目录
- Framework Preset：Other
- Build Command：无
- Install Command：无
- Output Directory：`.`

请只部署此目录，不要部署 `FB_Live_Data`、原始音视频、模型缓存、程序目录或本地会话令牌。项目的 `vercel.json` 已限制脚本为同源静态文件、API 连接为 `127.0.0.1`，并关闭来源泄露与搜索索引。

若出现 403，请使用本次启动的新链接，并确认本地工具允许当前 Vercel 网页的完整来源地址。若连接失败，请确认工具仍在运行、网页使用当前链接，且浏览器已允许本地网络访问。手机上的网页无法连接另一台电脑的 `127.0.0.1`。
